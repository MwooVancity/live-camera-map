# Hunt batch 4: US states and Canadian provinces not yet built (2026-11-25)

Goal: close part of the gap (Argos lists about 74,500 US cameras, we have about 5,500). Method: curl with User-Agent `worldtrafficcameras-research`, 2-4 s between requests, about 110 requests, no login, no key, no form. robots.txt read for every host touched.
