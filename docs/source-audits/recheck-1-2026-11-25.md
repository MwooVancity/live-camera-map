## Owner, list and coordinates (VERIFIED)

- Owner: Departamento Autonomo de Estradas de Rodagem (DAER-RS), state agency. Page `https://www.daer.rs.gov.br/cameras-de-monitoramento` (HTTP 200) is a Google-Maps page driven by `https://www.daer.rs.gov.br/themes/modelo-institucional/js/pagina.listalocal.mapacameras.js`.
- That script loads the list from `https://www.daer.rs.gov.br/cameras-de-monitoramento/listfilho?carregarlocaisrelacionados=true` (HTTP 200, application/json, 337 KB, no key). It holds 54 child pages; each has `urlamigavel`, title and `locais[].entidade.pontos` = "(lat,lng)". 36 of 54 have coordinates, 18 have none.
- Per-camera picture: the script calls `https://www.daer.rs.gov.br/_service/mapacameras?urlamigavel=<slug>&alttemplate=pagina.listalocal.mapacameras.conteudolocal`; the returned HTML contains `<img class="cameraRodovia" src="https://camerasdaer.perkons.com:60000/DAER-6716">` (example: slug ers-389-osorio, ERS-389 Osorio KM 14). Only 24 of 54 slugs returned a picture id; 24 unique ids.
- Picture host: `camerasdaer.perkons.com:60000` returned no connection (curl exit 7) for the picture and for robots.txt: "could not open", UNKNOWN whether it is a still image or a stream, whether it needs a referer, whether it is stable. Perkons is a private company, not the road owner.
- Count with coordinates AND picture id: 18 of 54.

## Licence and terms (VERIFIED, nothing permits reuse)

- `https://www.daer.rs.gov.br/termos-de-uso` (HTTP 200) contains only browser requirements (recommended browsers, JavaScript, CSS). It has no sentence about reuse, copying, linking or commercial use. Not a licence.
- No Creative Commons or open-data licence link on the home page or camera pages (grep for licen/dados-abertos/creative found none). Camera pages carry `data-credito=""` (empty credit).
- Robots: `https://www.daer.rs.gov.br/robots.txt` = `User-agent: *` / `Allow: /` (VERIFIED). Robots does not block, but robots is not a licence.
