# NZTA (Waka Kotahi) Traffic and Travel API: written permission request

To: service@nzta.govt.nz (the address on the NZTA API terms page, clause 19, read 2026-11-24)
Subject: Question: listing NZTA traffic camera links on an advertising-supported directory

Hello,

I run World Traffic Cameras (worldtrafficcameras.com), a free public directory of traffic camera links with a free map. It shows ads beside the data, so use is commercial. We do not copy, host, resize or change any camera picture: each camera name is a link to the official picture address provided by the Traffic and Travel API. We never charge users.

We would like to list the NZTA, Auckland Transport and Transport for Christchurch cameras this way. The Traffic and Travel API Terms of Use (clauses 2, 3(d) and 7(a)) allow publishing travel information but also say the information may not be used for commercial purposes unless expressly permitted, so we cannot tell whether an advertising-supported, link-only directory is allowed.

Please confirm in writing:
1. Whether listing and linking to the camera picture addresses on an advertising-supported site, without charging users, is permitted.
2. The credit wording you want shown.
3. Whether registration is required for this, and how to register.
4. Clause 11 asks for consent to link to your website: do you consent to links to the trafficnz.info camera addresses?

We will credit you on every page that shows these cameras and honour your limits.

Thank you.
Michael Woo
